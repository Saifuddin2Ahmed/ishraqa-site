# إشراقة يومية

الموقع الرسمي لتطبيق «إشراقة يومية»: **[ishraqa.app](https://ishraqa.app)**

## المحتوى

| المسار | الصفحة |
|---|---|
| `/` و`/en/` | الصفحة الرئيسية |
| `/about/` | عن إشراقة |
| `/a/` | المقالات |
| `/app/` | التطبيق على الويب |
| `/privacy/` و`/terms/` | الخصوصية والشروط |
| `/delete-account/` و`/child-safety/` | حذف الحساب وسلامة الأطفال |
| `/contact/` | التواصل |

## النشر

يُنشر الموقع عبر GitHub Pages من الفرع `main`. صفحات المقالات تُبنى تلقائيًا كل يوم
من مكتبة المقالات (`tools/build_articles.py`) عبر GitHub Actions.
